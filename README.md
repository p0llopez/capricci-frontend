## 🧞 Commands

All commands are run from the root of the project, from a terminal:

| Command               | Action                                           |
| :-------------------- | :----------------------------------------------- |
| `npm install`         | Installs dependencies                            |
| `npm dev`             | Starts local dev server at `localhost:4321`      |
| `npm build`           | Build your production site to `./dist/`          |
| `npm preview`         | Preview your build locally, before deploying     |
| `npm astro ...`       | Run CLI commands like `astro add`, `astro check` |
| `npm astro -- --help` | Get help using the Astro CLI                     |
| `npm format`          | Format the code with prettier                    |
| `npm format:check`    | Check the code format with prettier              |
| `npm lint`            | Run lint                                         |
| `npm lint:fix`        | Run lint and fix                                 |
| `npm prepare`         | Run format and lint                              |
